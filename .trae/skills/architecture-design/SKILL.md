# 架构设计技能

## 核心功能

- **系统架构规划**
- **模块划分与职责定义**
- **技术栈选型建议**
- **性能与可扩展性评估**
- **架构评审与优化**

## 使用场景

- 新项目技术方案设计
- 现有系统架构优化
- 技术债务评估
- 团队架构培训

## 架构类型

- 单体应用架构
- 微服务架构
- 事件驱动架构
- 领域驱动设计
- 服务网格架构

## 调用示例

```
用 architecture-design skill 设计一个电商系统的技术架构
使用 architecture-design 技能评估现有系统的可扩展性
```
