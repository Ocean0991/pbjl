# DevOps流水线技能

## 核心功能

- **CI/CD流水线配置**
- **容器化部署方案**
- **自动化测试集成**
- **监控告警设置**
- **环境管理策略**

## 使用场景

- 自动化部署流水线搭建
- 容器化应用部署
- 开发测试环境管理
- 生产环境监控

- Jenkins
- GitHub Actions
- GitLab CI
- Docker
- Kubernetes
