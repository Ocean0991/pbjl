## 图标设计规范
- 尺寸： 24x24px（Tab Bar）、20x20px（功能图标）、40x40px（大图标）
- 格式: PNG（透明背景）
- 颜色: 黑白（未选中）、黑色（选中）、功能色（根据类型）
- 风格: 线性图标、线宽 2px、圆角 2px
## 使用建议
1. 可以使用 iconfont 或 iconpark 等图标库
2. 建议使用 SF Symbols（iOS 风格）
3. 可以使用 Figma 或 Sketch 设计自定义图标
4. 临时测试时可以使用占位符图片或文字代替
## 注意事项
- 所有图标文件需要放在 assets/icons/ 目录下
- 文件名使用小写字母和连字符
- 确保图标在不同背景下都清晰可见
- Tab Bar 图标需要同时提供选中 and 未选中状态
