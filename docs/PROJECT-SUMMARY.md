# Runna 跑步教练小程序 - 项目总结

## 项目概述
这是一个专注于跑步训练的微信小程序，核心定位是**跑步教练**，帮助用户根据个人情况生成训练计划并提供专业建议。

## 核心功能

### 1. 用户建档 (Onboarding)
- 5步引导流程
- 基本信息（昵称、性别、出生年份）
- 身体数据（身高、体重、静息心率）
- 跑步经验（最长距离、每周跑量、是否完成过10公里）
- 目标设置（比赛类型、比赛日期、目标类型）
- 训练偏好（每周训练天数、偏好训练日）

### 2. 训练计划生成
- 根据用户档案自动生成个性化训练计划
- 支持多种比赛类型（5公里、10公里、半马、全马）
- 智能分期（基础期、提升期、巅峰期、减量期)
- 动态调整长距离跑距离
- 根据训练天数分配训练任务

### 3. 讯练执行与记录
- 今日训练展示
- 训练详情查看
- 手动记录训练完成情况
- 支持多种训练类型（轻松跑、长距离、质量课、恢复跑、休息)

### 4. AI教练建议
- 基于训练数据提供个性化建议
- 训练负荷监控
- 恢复建议
- 激励反馈
- 比赛倒计时提醒

### 5. 训练负荷管理
- ATL/CTL/TSB 计算
- 训练负荷趋势分析
- 风险评估与预警
- 恢复建议生成
### 6. 计划日历
- 月视图日历
- 周视图训练列表
- 训练完成状态标记
- 计划概览展示
### 7. 训练记录
- 跑量统计（本周/本月/总跑量)
- 训练负荷展示
- 训练记录列表
- 空状态提示
### 8. 个人中心
- 用户信息展示
- 训练档案查看
- 设置选项
- 统计数据展示
## 技术架构
### 前端技术
- 微信小程序原生开发
- WXML/WXSS/JS
- CommonJS 模块化
### 核心模块
- **plan-generator.js** - 训练计划生成引擎
- **coach-advisor.js** - AI教练建议系统
- **load-engine-v2.js** - 训练负荷计算引擎
- **calendar-reschedule-engine.js** - 动态日历重排系统
- **database-models.js** - 数据库模型定义
### 数据管理
- 本地存储（wx.setStorageSync）
- 状态管理（store.js）
- 数据规范化（normalizeState）
## 设计规范
### 配色方案
- 主色调：黑白配色
- 功能色：绿色（成功）、橙色（警告)、红色(错误)、蓝色(信息)
### 字体规范
- 大标题： 32px Bold
- 页面标题: 24px Semibold
- 卡片标题: 20px Semibold
- 正文: 16px Regular
### 间距规范
- 基础单位: 4px
- 常用间距: 8px, 12px, 16px, 24px
- 页面边距: 16px
### 组件规范
- 按钮: 高度 56px / 圆角 12px
- 卡片: 圆角 16px / 阴影轻微
- 输入框: 高度 48px / 圆角 12px
